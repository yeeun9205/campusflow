# CampusFlow 소스 프로젝트
대학 시간표·챗봇 UI·학습 계획·순공 기록과 로컬 알림 데모.

## 실행
1. ZIP 압축을 풀고 VS Code에서 폴더를 엽니다.
2. VS Code의 Live Server 확장을 설치합니다.
3. index.html을 우클릭하고 Open with Live Server를 선택합니다.
4. 또는 Python이 있다면 폴더 터미널에서 `python -m http.server 5500`을 실행하고 http://localhost:5500 으로 접속합니다.
5. 설정·자료 → 일정 알림에서 알림을 켜고 저장합니다. 기본값: 매일 오전 9시, 마감 5일 전.
6. 브라우저 알림 권한 요청 버튼을 클릭합니다. 브라우저와 OS에서 사이트 알림을 허용해야 합니다.

별도 npm 설치나 빌드가 필요 없습니다. Chrome/Edge 데스크톱에서 사용을 권장합니다.

## 파일
- index.html: 화면 구조
- styles.css: 반응형 UI
- app.js: 시간표, 달력, 챗봇 데모, 순공, 계획 로직
- notifications.js: 당일 요약, 마감 사전 알림, 알림함, 권한 요청
- test-notifications.js: 날짜 기준 알림 후보 테스트 (`node test-notifications.js`)

## 알림 동작과 한계
- 앱 페이지가 열려 있어야 작동합니다. 타이머는 60초마다 확인합니다.
- 백그라운드 탭은 브라우저에 의해 지연될 수 있습니다. 정시 전달을 보장하지 않습니다.
- 컴퓨터가 꺼졌거나 앱을 닫았을 때는 알림을 발송하지 않습니다.
- 알림 시각 이후 앱에 돌아오면 해당 날짜의 알림을 확인합니다.
- 5일 전 날짜에 앱을 열지 않았다면 과거 사전 알림을 소급해서 발송하지 않습니다.
- 당일 일정은 하루 한 번 요약합니다. 요약 이후의 변경 사항은 다음 요약에 포함되므로 앱에서 별도 확인하세요.
- 완료 과제는 제외하고, 날짜는 기기의 현지 시간 기준입니다.
- 같은 알림 ID는 브라우저 저장소 기준 중복 발송하지 않습니다. 여러 탭 동시 실행은 중복 가능성이 있으므로 한 탭만 사용하세요.
- 시스템 알림이 지원되지 않거나 거절되어도 앱 알림함에는 기록됩니다.
- 브라우저 저장소와 주소(origin)가 다르면 데이터가 공유되지 않습니다. 이전 HTML의 JSON 내보내기는 백업용이며 자동 가져오기는 아직 없습니다.
- 데모 초기화 시 알림 설정도 다시 기본값이 됩니다. 초기화 후 새로고침하세요.

## 실제 서비스에서 앱을 닫아도 알림을 받으려면
이 프로젝트는 Web Push 구현이 아닙니다. HTTPS 배포 + 서비스 워커 + Push 구독 + 서버 DB + 예약 작업이 필요합니다.
서버가 사용자 시간대와 알림 설정을 읽어 대상 일정을 조회하고 중복 방지 후 Web Push 또는 FCM으로 발송해야 합니다.
서비스 워커만 추가한다고 닫힌 앱에서 예약 타이머가 작동하는 것은 아닙니다. 서버 측 예약 발송이 필요합니다.

## AI
실제 LLM은 미연결입니다. 정해진 텍스트 형식만 처리하는 데모입니다. API 키는 프런트엔드에 넣지 말고 서버에서 관리하세요.
학기 기간/휴일/개인 일정은 아직 구현되어 있지 않습니다.

## 수정 버전
순공 기능 제거. AI 대화로 과제/시험 추가: 날짜가 없으면 오늘 여부를 질문하고 다른 날은 날짜를 요청합니다. 날짜는 2026년으로 제한합니다. 월간 날짜의 과제 버튼으로 대화를 시작할 수 있습니다. 알림은 설정한 N일 전부터 마감일까지 매일 한 번입니다. 0일은 당일만입니다. 실제 LLM은 미연결입니다. 현재 날짜는 기기의 월/일에 2026년을 적용한 데모이며 실서비스에서는 고정 연도를 해제해야 합니다.

## 월간 화면 정리
월간에는 반복 수업·휴강·보강을 표시하지 않고 과제·시험과 공부 계획만 표시합니다. 날짜 타일의 상시 과제 추가 버튼을 제거했고, 날짜를 눌러 상세창을 열면 과제 추가 버튼이 나타납니다. Google Calendar 연동은 아직 구현하지 않았습니다.

## 휴대폰 시간표 맞춤 버전
휴대폰 홈 화면에서는 안내 배너·통계·부가 카드를 숨기고 시간표를 우선 표시합니다. 5개 요일이 가로 스크롤 없이 표시되며 높이는 화면에 맞춰 조정합니다. 강의 상세는 탭해서 확인하세요. 극단적으로 작은 화면·큰 시스템 글꼴·가로모드에서는 세로 스크롤이 필요할 수 있습니다. 기존 Capacitor 프로젝트의 www/index.html, www/styles.css, www/app.js, www/notifications.js를 교체하고 npx.cmd cap sync android로 반영하세요.
